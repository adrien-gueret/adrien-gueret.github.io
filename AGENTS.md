# Portfolio maintenance

- This portfolio is bilingual: English is served from `/` and French from `/fr/`.
- Apply feedback about shared content, structure, or design to both language versions, even when the feedback identifies only one locale, unless it explicitly requests a locale-specific change.
- Translate editorial changes idiomatically and preserve the same meaning and tone across both languages.
- Validate both localized routes after changes.
- Do not modify `README.md` or delete files from `feedback/` unless the user explicitly requests it.
